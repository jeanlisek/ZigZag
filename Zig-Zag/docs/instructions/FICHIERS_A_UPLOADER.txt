❌ NE PAS UPLOADER
------------------
❌ admin/ (dossier SOURCE - contient le code React, node_modules, etc.)
   → C'est le code source, PAS nécessaire sur le serveur
   → Seulement le CONTENU de admin-dist/ doit être uploadé dans admin/

❌ admin-dist/ (dossier BUILD - ne pas uploader le dossier lui-même)
   → Uploader seulement son CONTENU dans admin/ sur le serveur

❌ game-app/ (nécessite Node.js - à déployer sur Vercel ou VPS)
❌ docs/ (documentation - pas nécessaire sur le serveur)
❌ sql/ (scripts SQL - pas nécessaire sur le serveur)
❌ node_modules/ (dépendances - jamais uploader)
❌ .env.local (variables d'environnement - ne jamais uploader)
❌ build-admin.sh (script local - pas nécessaire sur le serveur)
❌ .git/ (dossier Git - jamais uploader)

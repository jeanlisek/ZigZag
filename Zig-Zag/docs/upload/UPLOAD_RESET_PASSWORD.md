# 📤 Upload reset-password.html sur zig-zag.fun

## 🎯 Méthode : Via FTP (FileZilla ou similaire)

### Étape 1 : Se connecter via FTP

1. **Ouvrez FileZilla** (ou votre client FTP)
2. **Connectez-vous** avec vos identifiants Hostinger :
   - **Hôte** : `ftp.zig-zag.fun` ou `zig-zag.fun`
   - **Nom d'utilisateur** : (votre identifiant Hostinger)
   - **Mot de passe** : (votre mot de passe FTP)
   - **Port** : `21` (ou `22` pour SFTP)

### Étape 2 : Naviguer vers le bon dossier

1. Dans la partie **droite** (Serveur distant), naviguez vers :
   - `public_html/` 
   - OU `www/`
   - OU `domains/zig-zag.fun/public_html/`
   
   (Le chemin exact dépend de votre configuration Hostinger)

### Étape 3 : Uploader le fichier

1. Dans la partie **gauche** (Ordinateur local), naviguez vers :
   - Le dossier où se trouve `reset-password.html`
   - Chemin : `C:\Users\sapon\Downloads\2025-20251231T114815Z-1-001\reset-password.html`

2. **Glissez-déposer** `reset-password.html` depuis la partie gauche vers la partie droite

OU

3. **Clic droit** sur `reset-password.html` → **Upload**

### Étape 4 : Vérifier

1. Vérifiez que le fichier apparaît dans `public_html/` sur le serveur
2. Vérifiez les **permissions** : `644` (lecture/écriture pour propriétaire, lecture pour autres)

### Étape 5 : Tester

1. Ouvrez dans votre navigateur : `https://zig-zag.fun/reset-password.html`
2. La page devrait s'afficher correctement

## 🔧 Alternative : Via le File Manager de Hostinger

### Si vous préférez utiliser l'interface web Hostinger :

1. **Connectez-vous** à votre panneau Hostinger
2. Allez dans **Files** → **File Manager**
3. Naviguez vers `public_html/` (ou `www/`)
4. Cliquez sur **Upload**
5. Sélectionnez `reset-password.html`
6. Attendez la fin de l'upload
7. ✅ C'est fait !
